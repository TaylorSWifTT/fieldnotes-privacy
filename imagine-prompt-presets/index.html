Imagine Prompt Presets Privacy Policy

Effective October 29, 2026.

Information stored in your browser

Imagine Prompt Presets stores the names and text of presets you create in Chrome's local extension storage. These presets stay in the same Chrome profile and are not synchronized by this extension to other devices or sent to the developer.

Access to Grok Imagine

The extension runs on grok.com and www.grok.com to find the Imagine editor and show preset controls. It reads the editor text when you choose Save current and changes it when you select a preset. It does not automatically submit prompts or start generation.

When inserted into the editor, prompt text becomes accessible to the Grok website. Grok is a separate service with its own terms and privacy practices. This extension is independent of xAI and Grok.

No developer data collection

The extension does not send data to the developer or third parties. It includes no analytics, telemetry, advertising, remote code, or extension backend. The developer does not sell preset data or use it for advertising, creditworthiness, or lending decisions.

Deletion

You can delete individual presets from the menu. Uninstalling the extension removes its local extension storage.
